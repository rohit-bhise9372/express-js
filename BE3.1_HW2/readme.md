# BE3.1_HW2 - Express.js Basic Routes

## 📌 Project Overview

This project demonstrates how to create a basic web server using **Node.js** and **Express.js**.

The application defines multiple GET routes for different pages such as Home, Sign In, Booking, Kids Clothing, and Blog. It also uses the `dotenv` package to configure the server port through environment variables.

---

## 🚀 Technologies Used

- Node.js
- Express.js
- dotenv
- JavaScript
